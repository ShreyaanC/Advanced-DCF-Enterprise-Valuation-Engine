A professional-grade financial engine designed for intrinsic value calculation and equity research. This tool streamlines complex valuation modeling into a sleek, interactive dashboard.

## 📌 Overview
This DCF (Discounted Cash Flow) Analyzer provides a robust framework for estimating the enterprise and equity value of a company. Developed by **Shreyaan Chauhan**, it is specifically optimized for the Indian financial context, handling Lakhs/Crores formatting and standard valuation benchmarks.

## 🚀 Key Features
* **Dynamic DCF Schedule**: Real-time generation of discount factors and discounted cash flows based on user-defined WACC.
* **Automated Metrics**: Instant calculation of NPV, IRR, Payback Period, and Terminal Value using the Gordon Growth Method.
* **Equity Valuation**: Automated derivation of Share Price by accounting for Net Debt and Shares Outstanding.
* **Smart Data Entry**: Features a "Quick Paste" area to instantly parse comma-separated cash flow data.
* **Interactive Visualization**: Integrated Chart.js trajectory mapping to compare undiscounted vs. discounted flows.
* **Professional Exports**: One-click "Export CSV" and "Copy Summary" features for reporting.

## 🛠️ Tech Stack
* **UI/UX**: HTML5, Tailwind CSS.
* **Logic Engine**: Vanilla JavaScript (Financial Mathematics).
* **Data Visualization**: Chart.js.
* **Iconography**: FontAwesome.
